# App conventions

<context>
These are the conventions for any app created from this project template. They
complement the workspace rules in `CLAUDE.md`. Follow them whenever you add or
change application code in this project.
</context>

<structure>
- Backend: a single Express server in `server.js`.
- Frontend source: `web/` (`web/index.html`, `web/src/main.jsx`, `web/src/App.jsx`, `web/src/styles.css`). Add new components alongside `App.jsx`.
- Build output: `public/` is generated by Vite. Never edit `public/` directly — it is overwritten on every build.
</structure>

<rules>
1. Bind the server to `process.env.PORT` (`const PORT = parseInt(process.env.PORT || "3000", 10);`). Never hardcode a port or scan for a free one.
2. After editing anything under `web/`, run `npm run build` so `public/` (and the preview) reflects the change. The preview does not auto-rebuild.
3. Airgapped only: no CDN `<script>`/`<link>` tags, no external fonts, no browser-side Babel, no esm.sh import maps. Every JS/CSS/font asset comes from npm and is bundled by Vite.
4. Keep all frontend URLs relative (no leading slash) so the preview proxy can resolve them.
5. Styling uses Tailwind v4 via `web/src/styles.css`; brand tokens live in the `@theme` block.
</rules>
